# Tomato-Plant-Disease-Identifier-STICS-Project
A deep learning-based tomato leaf disease classification system built with TensorFlow and EfficientNetB0. Trained on real-field tomato images using a two-phase transfer learning approach frozen base training followed by fine-tuning. Tested across multiple optimizers (Adam, Nadam, Adagrad, RMSprop, SGD) for comparative analysis.
